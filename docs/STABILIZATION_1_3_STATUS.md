## A. 일일 학습

- `learning-budget-policy.js`에서 8개 활동의 배분을 관리한다. 30/45/60분 합계가 정확히 일치한다.
- 조회 시 신규 미시작 계획만 이관한다. 진행/완료/과거 계획과 이미 제출 증거가 있는 계획은 보존한다.
- 예산만 바뀌는 미시작 계획은 과제 ID와 선택한 단원을 유지한다.
- `curriculumVersion=1`과 별도로 `allocationPolicyVersion=2`를 사용한다.
- 주간 기본 분모는 8, 실제 옛 계획은 저장된 과제 수를 그대로 사용한다.
- 일일 경로에서 최근 점수에 따른 5/10/15분 추가 대기를 제거한다. 명시한 보호자 최소 시간은 보존한다.
- 설정 출처는 raw timer config에서 확인한다. 저장된 과목/레벨 값은 명시 설정으로 취급한다. 없는 기본값만 과목 배정의 60%(분 단위 내림, 최소 1분) 이내로 제한한다.
- 최소 시간과 활동 배분이 충돌하면 관리자 저장을 막고 두 숫자를 표시한다. 기존 충돌 설정은 보존하며 학생에게 초과 가능성을 안내한다.
- 퀴즈 진입은 타이머 상태 API를 사용하고 DOM 클래스 유무로 판단하지 않는다.
- 기기 저장이 미완료/실패이면 해당 사용자 보고서를 완료 증거로 사용하지 않는다. 저장 재시도와 답안 보존 안내를 제공한다.
- 서버 전송은 기존 동기화 경로로 처리한다. 기기 저장 완료와 서버 확인 완료를 동일시하지 않는다.
- 미확정 채점의 오래된 기록을 정상 제출로 완화하는 변경은 하지 않았다. 일일 활동 완료는 채점 가능한 전체 제출 증거를 계속 요구한다.

### 저장 설계 보완

- optimistic cache와 실제 committed rows를 분리했다.
- 큐 실행 시 committed rows와 비교하므로 첫 쓰기 실패 후 동일 내용 재시도도 실제로 저장된다.
- 키별 revision/error를 추적한다. 한 키 성공으로 다른 키 실패를 지우지 않는다.
- 복구는 최신 desired snapshot을 저장하며 오래된 실패 값으로 되돌리지 않는다.
- 오답 본문과 subject 목록 메타데이터를 같은 transaction에 저장한다.
- memory-only overflow가 있으면 flush는 실패한다. DurableStore가 snapshot을 인수하면 overflow 소유권을 넘겨 오래된 값 재생을 막는다.
- 고난도 저장 설계와 구현 diff를 별도 Astra 검토했고 지적 사항을 반영했다.

## B. 일요일 복습

- 순수 후보/선택 로직을 `weekly-review-policy.js`로 분리했다.
- 공개 시험 6 + 주중 4를 기본으로, 부족한 쪽을 상호 보충한다. 최대 10개이며 중복으로 채우지 않는다.
- 사용자·한국 날짜·주차·전체 제출 여부·정답 유일성·검수 보류 상태를 확인한다.
- 동일 문항은 양쪽 sourceReferences를 보존한다. 지문/범위가 다르면 별개로 유지한다.
- 서버 확인 8초 후 주중 오답으로 시작할 수 있다. 비공개/응답 실패를 구분한다.
- 시작한 세션은 늦은 응답으로 문항·답안·위치가 바뀌지 않는다.
- 기존 세션 키와 제출 완료 상태를 보존한다.
- 나중에 공개된 시험은 별도 최대 6문항 보충 세션으로 제공한다. 기본 세션 완료를 취소하지 않는다.
- 보충 세션 도중 새로고침하면 저장한 위치와 답안을 복원한다.
- 계정 변경/날짜 변경 후 저장을 차단한다. 오류 후보뿐인 상태와 실제 오답 없는 상태를 구분한다.
- 복습 세션은 현재 preference 저장 경로를 사용한다. 별도의 기기 간 복습 이어하기를 검증·추가한 것은 아니다.

## C. 문항과 정답 검증

### 완료한 검증 장치

- 전체 일반 수학 738 템플릿 inventory와 고정 seed 검사를 추가했다.
- 별도의 정수 분수 연산 oracle를 구현했다. 프로덕션 계산 함수를 정답으로 재사용하지 않는다.

- 미지원 514개는 inventory에 `unreviewed`로 명시한다. 형식 검사 통과를 독립 계산 완료로 표시하지 않는다.
- 오답 인덱스, 수학적으로 동치인 선택지, 0 나눗셈, 질문 변조 등을 주입했을 때 실제로 실패하는 검사가 있다.

- 기존 math-formula.test.js의 공식 61~120 독립 기준값 검사와 초등 공식 16개 계산 검사도 함께 실행한다. 이 결과를 일반 수학 738개 커버리지에 합산하지 않는다.
- 국어/영어/모의고사 및 영어 단어 변형 문항의 inventory 734개를 구성했다. 구조·정답 유일성·근거 문장 인덱스를 검사한다.
- 그중 20개는 정답 근거와 선택지별 오답 이유를 기록했다. 나머지 714개는 의미 검수 완료가 아니다.
- 콘텐츠 hash가 바뀌면 재검수를 요구한다. inventory 갱신 명령은 새 문항을 자동 승인하지 않는다.

### 아직 필요한 콘텐츠 검수

전수 의미 검수는 완료하지 않았다. 이 문서를 모든 수학/독해 정답이 정확하다는 인증으로 사용하면 안 된다.

독립 oracle 미지원 생성기 지원 확대와 독해의 지문 근거·각 오답 이유 검수를 계속할 수 있다.
역사/과학 사실에 대한 외부 원자료 전량 대조도 완료하지 않았다.
새로운 오답 판정 완화나 과거 기록 자동 재채점은 적용하지 않았다.
