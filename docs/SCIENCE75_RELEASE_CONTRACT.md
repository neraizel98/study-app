# Science75 integration and release contract

Local implementation and emulator verification: 2026-11-13. This document does not authorize or claim production deployment.

- `legacy55-v1`: 55 questions; reading/English/math15 each, hanja10. Existing unversioned snapshots remain legacy. Existing section times and questions remain unchanged.
- `science75-v1`: 75 questions; the same55 plus science20. Five saved sections use20/20/20/10/25 minutes, with the existing5 minute break after English. A completed normal science first submission (exactly10 Boolean first answers) in the target KST week enables this version. Prediction, draft, hint/review, foreign learner and partial records do not enable it.
- Questions, version, sections, quotas and times are frozen when generated. A later study record does not alter an existing online or printed exam. Paper grading retains the original version and questions.
- Science uses only this week's actually studied units. Largest remainder allocation uses unique session first-answer count. Each selected unit must have60 unique assessment fingerprints. Same-week questions are excluded; earlier-week questions return only after unseen questions, oldest first. A shortage blocks the75 exam and does not downgrade it to55.
- The normal learner results UI still checks the server's `published === true` before showing results. Admin OMR scoring creates an unpublished result. Initial answers and first scores remain immutable. Existing Firestore `canUse` read access still permits a linked learner to read the raw unpublished payload; this is a confirmed pre-existing limitation, not server-enforced answer secrecy. Changing that policy requires a separate history/manifest migration and is excluded from this release.

Deployment must treat static JS/assets/service worker and `firestore.rules` as a coordinated release. Old deployed55-only rules cannot accept science75 snapshots. New rules retain55 compatibility and check exact version, total question/first-answer counts, five section IDs/subjects/first-answer counts15/15/15/10/20, section durations20/20/20/10/25 minutes, nonnegative integer quotas and area sums, roles and immutable transitions. Per-question source content and subject/order consistency remain client integrity checks, as in legacy55; rules do not authenticate individual authored questions or correct answers. Production rules and static assets have not been deployed in this work.

New science75 submitted snapshots carry `sourceSnapshotVersion: 'questions-v1'`. Every source question remains intact in `questions`; repeated source passages/tables/fingerprints are removed from top-level and section first-answer copies, and reports retain one initial-attempt array. `MockExam.hydrateSnapshot` restores source materials from the immutable question snapshot when Firestore get/list, local restore and result rendering read these submissions. Question text, choices, selected/correct answers, first score and version remain in every answer record. Legacy55 serialization remains unchanged.

Assessment tables store rows as `{cells:[...]}` objects because Firestore rejects arrays directly nested inside arrays. Online and paper renderers accept both this persisted shape and earlier local array rows. The source values remain present in the table and passage text.
