# 영어 읽고 쓰기 1단계 구현 명세

## 적용 범위

초6과 중1에서 각각 2단원, 단원마다 기초·표준·도전 지문 각 1개를 선정했다. 기존 지문 12개에 3문항씩 총 36문항을 추가했다.

| 레벨 | 적용 단원 | 지문 |
| --- | --- | --- |
| 초6 | 달을 바라보는 밤, 음식이 식탁에 오기까지 | er1-p0~p2, er3-p0~p2 |
| 중1 | 중1 독해 1·2단원 | mr1-unit1-p1~p3, mr1-unit2-p1~p3 |

## 학습 흐름

기존 ‘이 지문 연습’ 또는 오늘학습의 퀴즈 시작 버튼을 누르면 쓰기 3문항을 먼저 풀고 독해 7문항을 푼다. 구절 조합, 형태 바꾸기, 영어 단답 순으로 입력 부담을 높인다. 예를 들어 달빛 지문에서는 눈에 도달하는 빛의 출처를 구절로 조합하고, 제시한 동사의 시제를 바꾸고, 영어 질문에 빛의 출처를 짧게 답한다. 문법 문제에 지시한 주어나 시제를 적용하는 능력과 본문 내용 이해를 구분해 표시한다.

기존 학습 시간 잠금, 해당 단원의 오늘학습 제출, 다음 활동 연결을 유지한다. 퀴즈와 재도전 화면에 번역을 표시하지 않는다. 근거 힌트와 채점 후 근거는 영어 원문을 사용한다.

## 채점과 기록

- 문항마다 허용 표현을 작성한다. 대소문자, 끝의 마침표 등, 아포스트로피 표기 차이를 허용한다. 이름과 대명사 둘 다 자연스러우면 허용 표현에 함께 적는다.
- 영어 단답은 검수된 정답과 명시한 대표 오답을 판정한다. 그 밖의 답안은 ‘확인 필요’로 분리해 예시 답과 본문 근거를 보여 준다. 답안은 기록하고 채점된 문항 점수, 오답 노트, 오답 재도전에서 제외한다. 결과 화면과 기록에는 확인 필요 수를 별도로 표시한다. 보호자가 상태를 바꾸는 기능은 이번 범위에 없다.
- 처음 선택한 구절과 입력 중인 답을 세션에 저장한다. 최초 답안·힌트 사용·재도전 답안은 기존 보고서 경로를 사용한다. 동일 세션의 최초 결과는 재도전이나 새로고침 시 보존한다.
- 쓰기 3문항은 지문별 고정 ID를 쓰고 기존 7일 노출 기록을 공유한다. 7일 안에 같은 쓰기 문항을 두 번 제출했다면 기존 독해 문항으로 구성한다. 확정 오답은 오답 복습에서 다시 풀 수 있다.
- 기존 미학습 지문 평가, 쓰기팩이 없는 지문과 레벨의 연습을 유지한다. 쓰기팩은 읽기·형태 변환·단답이 섞인 연습이므로 기존 독해 난이도 판정에서는 분리한다. 모든 답안이 채점됐고 힌트를 쓰지 않은 최초 점수는 기존 학습 시간 규칙을 적용한다. 오늘학습은 단원에 맞는 전체 퀴즈의 제출로 완료한다.
- 다른 과목, 진행 중인 계획, 학습 시간 규칙과 한자를 유지한다. 후속 단계에서 과학·사회 읽고 설명하기와 3묶음 시간표를 설계한다.

## 검증 범위

- Node 전체 회귀 검사 277개를 통과했다. 지문별 근거 문장, 허용 답안, 본문과 모순되는 답안, 확인 필요 답안, 불완전한 제출, 재도전 후 최초 답안 보존을 확인했다.
- 390px Chrome에서 초6 오늘학습으로 10문항을 제출하고 다음 활동을 열었다. 구절과 입력 초안 복원, 같은 세션의 중복 제출 방지, 확정 오답만 재도전, 통합 성적표와 학생·관리자 답안 상세, 쓰기 문제 노출 상한과 중1 팩 진입을 확인했다.
- 관리자 상세는 로컬 테스트 기록으로 검증했다. 실제 계정의 클라우드 동기화와 운영 배포 검증은 별도 단계다.

## 모의고사 연결과 문항 수 검증 추가

2026-11-11 요청에 따라 일반 독해 기록과 모의고사 연결을 추가했다. 최초 구현에서는 새 쓰기 36문항이 일반 독해에 적용됐고, 모의고사는 별도 시험 전용 지문을 사용했다. 확인 필요 단답을 포함한 일반 독해 기록에서 확정 채점한 문항만 출제 범위 근거로 읽도록 수정했다.

모의고사는 초6·중1 시험 전용 지문 8개에 검수한 형태 변환 16문항을 추가했다. 학습한 형태 변환 기록이 있으면 해당 레벨의 새 시험 지문에서 문장을 직접 입력한다. 시험용 문장과 허용 답안은 시험 스냅샷에 함께 저장한다. 종이 시험과 OMR의 기존 단답형 칸도 사용한다. 일반 독해의 확인 필요 단답은 모의고사 자동 채점 문항으로 옮기지 않는다.

| 시나리오 | 확인 기준 |
| --- | --- |
| 일반 영어 독해 전체 116지문 | 신규 노출과 최근 노출 소진 상태 모두 10문항 |
| 쓰기 12지문 | 3문항 쓰기와 7문항 독해, 노출 한도 뒤 기존 독해 10문항 |
| 확인 필요 답안이 있는 학습 기록 | 확정 문항을 출제 범위로 인식, 불완전 기록은 제외 |
| 주 5일 학습과 신규 쓰기 1~2일 학습 | 국·영·수 각 15, 한자 10, 총 55문항 |
| 같은 주 1~3회 | 총 165개 서로 다른 문항으로 시작·제출 |
| 새 영어 형태 변환 | 대소문자·끝 구두점·검수한 대명사 허용, 의미 반대 답 거절 |
| 종이·OMR | 영어 단답형 칸과 허용 답안 스냅샷, 채점 뒤 공개 대기 |
| 향후 새 문항·과목 | AGENTS.md의 문항 수·시작·제출·저장 검증 적용 |

문항 은행은 유한하다. 모든 시험 지문을 같은 주에 이미 노출했거나 학습 근거가 전혀 없는 경우까지 무조건 시작된다고 보장하지 않는다. 이 경우 기존의 구체적인 부족 사유를 표시한다. 이번 검증은 영어 독해와 모의고사를 대상으로 하며, 모든 과목의 일반 퀴즈 전체를 새로 검증한 결과는 아니다.

추가 검증 결과 Node 전체 회귀 검사 280개가 통과했다. 종이 시험의 영어 허용 답안 채점과 OMR 단답형 칸을 검사했고, 모바일에서 영어 입력 문항이 포함된 모의고사 55문항을 실제로 시작·입력·제출했다. 새로고침 뒤 답안과 마감 시간을 복원했고, 제출 기록 55개와 결과 공개 대기 상태를 확인했다.

영어 독해 116지문의 실제 연습 시작을 새 노출과 노출 소진 상태에서 각각 실행한 232회 검사도 통과했다. 모든 세션이 정확히 10문항이었고, 운영 페이지에 로드된 지문별 원본·확장 문항 은행은 11~18문항이었다.
