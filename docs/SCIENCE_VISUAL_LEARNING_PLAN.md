작성 2026-11-11. 구현 파일은 science_lab.html, science_lab.css, science_lab.js다.

## 참고에서 적용한 표현

사용자 링크 https://www.instagram.com/p/De6rZd7lL1e/ 와 연결된 원본 https://iamtechartist.com/every-joule/ 를 실제 화면에서 확인했다. 크림색 종이와 잉크선, 펼친 책 위의 입체 모형, 색으로 표시한 에너지 흐름, 예측 뒤 여는 설명, 전체에서 확대·단면·과정·직접 실험으로 이동하는 방식을 참고했다.

첫 시제품에는 독자적으로 그린 SVG 비커와 히터를 사용했다. 종이 노트의 두 페이지에 같은 모양의 비커를 배치하고 단면·입자·열의 흐름을 단계별로 켠다. 확대 단계는 비커를 가까이 보여 주고 눈금을 표시한다. 참고 사이트의 코드·그림 자산은 가져오지 않았다. 모형의 회전이나 실제 3D 렌더링은 제공하지 않는다. CSS와 SVG만 사용해 새 실행 의존성을 추가하지 않았다.

## 첫 개념과 물리 모형

질문은 ‘같은 에너지를 받으면 물의 양에 따라 온도 변화가 어떻게 달라질까?’다.

| 조건 | A | B |
| --- | --- | --- |
| 물의 질량 | 1kg | 2kg |
| 처음 온도 | 20℃ | 20℃ |
| 히터 전력 | 1000W | 1000W |
| 가열 시간 | 60초 | 60초 |
| 받은 에너지 | 60kJ | 60kJ |
| 온도 변화 | 약 14.3℃ | 약 7.1℃ |
| 마지막 온도 | 약 34.3℃ | 약 27.1℃ |

계산은 Q = Pt, ΔT = Q/(mc), 마지막 온도 = 처음 온도 + ΔT를 사용한다. 물의 비열은 4,200J/(kg·℃)로 어림한다. OpenStax에 제시된 물의 비열 4,186J/(kg·℃)와 Q = mcΔT 관계를 근거로 학습용 반올림 값을 선택했다.

근거는 OpenStax Physics 11.2 https://openstax.org/books/physics/pages/11-2-heat-specific-heat-and-heat-transfer 와 University Physics 2권 1.4 https://openstax.org/books/university-physics-volume-2/pages/1-4-heat-transfer-specific-heat-and-calorimetry 다.

컵이나 히터의 열용량, 외부 열손실, 증발과 끓음, 열팽창은 계산하지 않는다. 입력 검증은 0 이하 질량, 음의 시간, 잘못된 수치와 100℃ 이상 결과를 거절한다. UI는 각 비커의 물만 0.5kg·1kg·2kg 중에서 바꾸므로 허용 조건에서 끓지 않는다.

입자 그림은 정성 모형이다. 물의 양에 맞춰 같은 크기 점의 개수를 바꾸고, 온도가 오르면 점의 운동을 더 활발하게 표현한다. 점의 크기는 가열 전후 같다. 실제 분자의 크기·개수·궤적·속도 수치를 나타내지 않는다는 설명을 화면에 표시했다. 화살표는 히터에서 물로 들어가는 에너지의 방향을 뜻하며, 유체의 대류 궤적을 계산하지 않는다.

## 실제 학습 흐름

1. A·B 중 마지막 온도가 높은 쪽 또는 같은 결과를 예상한다.
2. 전체·확대·단면·열의 흐름·직접 실험 단계로 관찰한다.
3. 재생, 일시정지, 시간 막대, 처음부터로 0~60초를 비교한다. 기본 재생은 실제 60초를 약 8초로 압축한다.
4. 직접 실험에서 물의 양만 바꾸면 이전 예측·실험 결과·답안을 초기화한다. 같은 질량 조건도 비교할 수 있다.
5. 60초에 도달하면 이유 설명을 열고 식과 구체적인 결과를 읽는다.
6. 다른 질량, 통제 조건, 가열 시간, 입자 모형을 묻는 새 상황 4문항을 확인한다. 답을 수정해 다시 확인할 수 있다.

예측 전에는 재생과 시간 막대가 잠겨 있다. 설명과 확인 문항은 실험 종료 뒤 열린다. 정지 그림 모드에서는 같은 수치·설명을 시간 막대와 텍스트로 확인한다. 동작 줄이기 설정을 따르며 다른 화면을 보면 자동으로 일시정지한다. 버튼·슬라이더·예측·확인 문항은 키보드로 조작할 수 있다.

## 적용 범위

독립 시제품이며 성적과 입력을 서버나 오늘 계획에 저장하지 않는다. 학습 기록을 읽는 앱 스크립트를 로드하지 않는다. 과학 과목의 정식 진도·시간 배정·평가 연결은 후속 결정 항목이다. 기존 모의고사의 국·영·수 각 15문항, 한자 10문항, 총 55문항 계약은 이번 시제품과 연결하지 않는다.

문항·과목으로 정식 공개할 때에는 AGENTS.md의 일반 퀴즈·모의고사 정원, 시작, 제출, 저장 검증을 적용한다.

## 검증 결과

- science-lab.test.js의 계산·경계값 검사 2개가 통과했다. 1kg·2kg의 온도 변화 비율, 같은 에너지, 가열 시간 비율, 0초, 허용 질량과 끓음·잘못된 수치 거절을 확인했다.
- tests/science-lab-browser.cjs에서 390px Chrome의 예측 잠금, 재생·일시정지·시간 이동·초기화, 질량 변경 뒤 재예측, 같은 질량 비교, 설명 덮개, 4문항 확인을 검사했다. 키보드, 동작 줄이기, 배경 화면 전환 시 정지, 모바일·데스크톱 가로 넘침, 서버 통신이 없는 상태를 확인했다.
- 기존 모의고사 회귀 검사 mock-writing-readiness.test.js의 3개 검사도 통과했다. 시제품은 기존 과목과 기록 파일을 수정하지 않는다.
- 스크린샷은 저장소 밖 outputs/science-heat-prototype 아래의 science-390-experiment.png, science-390-explanation.png, science-desktop-cutaway.png다.
- 운영 배포와 실제 학습 계정 연결은 진행하지 않은 로컬 시제품이다. 물리 수치는 손실 없는 계산 결과이며 실제 비커 가열 실험의 측정값이 아니다.
