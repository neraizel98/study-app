# 과학 Level 1 구현 명세

작성: 2026-11-11. 상태: 구현 계약(설계 문서이며 구현·실계정·배포 완료를 뜻하지 않음).

## 1. 이번 완결 범위

- 정식 과목 ID `science`, 학생 이름 `과학`, 진입 `science.html`.
- Level 1 = 초6까지 연결되는 **초등 과학 핵심 탐구 입문 8단원**. 초등 전체 교육과정 완수나 특정 개정 교육과정 전 항목 충족이라고 표기하지 않는다.
- 4영역 × 2단원, 단원마다 의미상 독립된 20문항 이상, 1회 정확히 10문항. 최소 총160문항. 선택지 순서·수치만 바꾼 복제 문항은 독립 20문항에 포함하지 않는다.
- 본문 설명·예측·조작 가능한 도식·관찰 결론·10문항·최초 점수·오답·복습·새로고침 복원·공통 기록까지 한 단원을 끝까지 완성한다.
- Level 2/3 탭은 준비 상태와 범위를 설명하되 빈 퀴즈를 시작시키지 않는다. Level 1 품질을 확인한 뒤 순서대로 구현한다.
- 기존 미커밋 영어 패치와 `science_lab.html/js/css` 독립 prototype을 보존한다. 정식 페이지에서 prototype의 가상 수치를 실제 실험 결과처럼 재사용하지 않는다.

단원마다 학습목표3개, 핵심개념3~5개, 흔한 오개념2개, 생활 적용1개를 데이터로 작성한다. 문항은 개념확인/도식해석/조건비교/생활적용을 각각 최소4개씩 포함하고 나머지4개를 해당 단원의 관찰 목표에 배정한다. 10문항 선택에서도 가능하면 네 유형을 모두 포함하되 노출 선택 정책을 깨지 않는다.

실험에서 정성 모형만 제공하는 곳은 `원리를 살펴보는 모형이에요. 실제 크기·속도·양과 다를 수 있어요.`를 해당 장면 가까이 표시한다. 질량/열량 숫자를 쓰면 같은 물질·열손실 무시·상태변화 없음 같은 가정을 함께 적고 실제 식과 결과가 일치해야 한다. 검증할 수 없으면 숫자를 빼고 정성 비교로 구현한다.

## 3. 학습 화면과 시각 품질

### 공통 흐름

1. 질문 하나로 시작: `같은 시간 데우면 물이 적은 쪽과 많은 쪽 중 어느 쪽 온도가 더 오를까?`
2. 예측 선택: 틀려도 점수/오답노트/노출/숙달에 넣지 않는다. 건너뛰기 허용.
3. 탐구 장면: 단원에 의미 있는 `전체 보기 → 확대 → 속 보기 → 과정 → 직접 바꾸기` 5단계. 단순 동일 그림 확대를 5단계 완성으로 간주하지 않는다.
4. 관찰 이유: 조작 결과와 직접 연결된 한 문장 설명, 펼치는 핵심 원리 덮개.
5. 확인 퀴즈: 10문항, 결과, 오답 다시 풀기, 다른 단원/오늘 학습 돌아가기.

### 렌더링 구현 계약

- 별도 네트워크 라이브러리 의존 없이 SVG + CSS + requestAnimationFrame으로 정교한 층위·경로·단면·질감·그림자·클리핑을 구성할 수 있다. 3D 기술 자체보다 관찰할 과학 관계를 정확히 드러내는 것을 우선한다.
- 영역별 다른 실제 모형이 필요하다. 공통 원/박스의 색과 제목만 바꾸는 8단원은 불합격.
- 열 단원은 유리 용기 전/후면, 수면 타원, 액체 경계, 온도계, 열 전달 방향, 질량 조건 표시를 분리한다. 입자를 꾸밈 비처럼 흩뿌리지 않고 설명 대상과 연결한다.
- 지구는 명암/낮밤 경계/자전축/관찰점, 궤도는 앞뒤 가림과 진행 흔적, 은하는 여러 별과 구조·태양계 위치를 분리한다. 단순 궤도 타원 하나만으로 세 움직임을 퉁치지 않는다.
- 모형마다 재생/일시정지/초기화, 단계 이동과 입력이 작동해야 한다. 모션 정지 상태에서도 설명·문제 풀이 가능. 배경 탭에서는 RAF 중지. `prefers-reduced-motion`에서는 기본 정지.
- 모바일 360/390px, 데스크톱1280px에서 SVG 도식과 레이블이 겹치지 않게 다른 배치를 적용한다. 터치44px 이상. 색 이외에 라벨/모양/화살표로 뜻 구분. 포커스 표시와 키보드 조작.
- 초등 입문 학습에 아날로그 모형 스타일을 사용하되 장난감처럼 과도하게 튀는 효과는 줄인다. Every Joule은 학습 연출 참조이며 에셋·문구 복제 대상으로 삼지 않는다.

### 과학 식별색

저장소 `theme.css` 확인 결과 국어는 주황/갈색(`#b44f2b`), 영어는 초록(`#23845c`), 수학 타일은 파랑(`#1d4c8c`), 공식은 보라(`#5b4bb4`), 한자는 적갈색(`#8a2b2b`). 과학의 주색은 **진한 청록 `#086f78`**, 보조 바탕 `#e3f3f2`로 정한다. 공통 크림 `#fbf7ef`/본문 `#2b2620` 유지. 브랜드 기본 `--accent2`가 청록을 쓰는 오래된 CSS가 있으므로 전역 치환하지 말고 `body[data-subject="science"]` 또는 `.science-*` 범위에 적용한다. 최종 과목 카드 나란히 보는 실제 스크린샷으로 식별성 검사. 뜻을 색 하나에 의존하지 않는다.

## 5. 퀴즈·저장·숙달

- `QuizExposure.select(user,'science',unit.questions,10)`를 사용한다. 저장소 정책은 최근 **7일 rolling window**, 정상 노출2회까지. 달력 주2회라고 다르게 구현하지 않는다.
- 20문항이면 처음 두 회차는 신규10+신규10. 이후 정상 두 번째 노출 가능. 5회차부터 모두 소진하면 동일 단원 오래된 문항 복습10으로 시작하고 `review:true`/노출 이유를 보여준다. 정상 문제와 복습이 섞여도 한 문항이라도 한도 초과면 세션 전체 숙달근거 제외.
- 의미 fingerprint에는 실제 질문/정답/조건이 포함되어야 한다. ID만 다른 복제 문제를 신규로 세지 않는다. 시작시10개 미만이면 콘텐츠 오류 안내, 완료 점수 생성 금지.
- draft는 사용자+단원+sessionId 기준 LocalRepository preference에 저장. 선택한 문제 전체와 exposure, 현재 인덱스, 최초 답변, 후속 답변, 예측, 모형 단계/조건, 시간, 데이터 버전을 저장. 저장공간 예외는 기존 repository 안전 경로 사용.
- 첫 제출에서 `saveQuizResult(sessionId,'science',title,10,finalScore,initialScore,seconds,true,metadata)` 사용. metadata에 `levelId,unitId,unitTitle,domain,source:'science',contentVersion,attempts,initialAttempts,submittedAt,review,exposurePolicy,hintUsed`.
- 각 attempt: `questionId,question,choices,correctAnswer,answer,correct:boolean,round:1,conceptId,givens,exposure,context:{levelId,unitId,title}`. 실제 공통 오답 구조와 맞춰 `WrongNote` 경로로 적재.
- 예측은 별도 `prediction` 저장만, attempts에 넣지 않는다. 재도전은 같은 sessionId/initialAttempts/initialScore 유지. 중복 제출은 같은 기록 갱신, 새 학습으로 중복 계상하지 않는다.
- 리뷰·힌트·재도전은 완료 기록은 남지만 `StudyTimer.recordResult`와 숙달/승급의 새 증거에서 제외한다. 과학 evidence는 완결10문항+유효 Boolean 답10개만 인정하는 guard 필요.
- 결과는 `첫 풀이 7/10`과 `오답 복습 완료`를 분리. 첫 점수를 10/10으로 덮어쓰지 않는다.

### 오늘 학습: 8개 유지

`LearningBudgetPolicy.subjects`와 allocations는 **수정하지 않는다**. 현재 8개+30/45/60분 계약을 보존한다. 과학을 조용히 9번째로 붙이거나 영어 시간을 깎지 않는다.

오늘 페이지에는 8개 필수 활동 바깥에 `과학 탐구 · 선택 학습` 카드(추천 단원·최근 최초 결과·진입)를 둔다. `오늘 필수 8개 완료` 분모에는 넣지 않는다. 과학 페이지에서 오늘 학습 복귀 링크 제공. 과학 선택 학습 시간은 공통 과목 통계에 기록하되 기본 목표가 늘어난 것처럼 표시하지 않는다. 기존 총시간이 8개만 합산하는 곳은 `기본 계획 시간`과 `추가 과학 시간`을 구분하거나 전체 실제시간 포함 여부를 명시한다.

정식 일일 배분 편입은 이후 보호자에게 교체할 활동/요일/시간을 묻고 구현한다. 이번은 선택 학습으로 실제 사용 가능하게 완결한다.

### 모의고사: 최신 사용자 승인으로 과학20 추가, 신규75/기존55 공존

2026-11-11 최신 사용자 결정이 기존 AGENTS.md의 고정55 계약보다 우선한다. **과학 학습 근거가 있는 새 시험은 기존55+과학20=75문항**, 시험시간 기존70+과학25=95분, 기존 휴식5분 정책 유지. 과학 학습 근거가 없는 주의 새 시험은 기존55를 유지한다. 기존 생성/출력/진행/제출한55는 절대75로 재해석하지 않는다.

- 생성 시 `examVersion:'science75-v1'` 또는 기존 버전에 대응하는 `legacy55-v1`을 저장하고 문항·섹션·시간을 immutable snapshot으로 고정한다. 기존 무버전 저장본은 55 legacy로 해석하며 새 science75를 무버전으로 저장하지 않는다.
- 과목 배분: 국어15/영어15/수학15/한자10/과학20. 과학은 독립5번째 영역. 순서·섹션 offset·답안 index·페이지·OMR·제출검증·결과 분모를 **저장된 examVersion/sections**에서 읽는다. 전역 상수55→75 일괄치환 금지.
- 과학 진입 자격: 대상 주에 실제 완결된 정상 과학 학습 근거가 있고 해당 범위의 시험은행이 검증되어 있어야 한다. 예측/draft/다른사용자 기록만으로 science75 활성화 금지. 한 번 생성한 시험은 이후 과학기록 추가/삭제와 무관하게 고정.
- 학습 범위: 일반 과학 기록의 levelId/unitId/domainId와 실제 학습량을 집계한다. 1일/2일/5일 모두 실제 배운 단원에만 출제. 과학20 안에서 학습 영역별 비중을 가장큰나머지 방식 등 결정적 배분으로 정수화한다. 같은 영역의 단원도 학습량을 반영하되 중복 기록/재도전으로 비중을 부풀리지 않는다.
- **최소 범위 한 단원만 배운 주에도 1~3회 각20개 의미상 독립 문항을 확보한다. 단원당 평가 전용60개, 8단원 총480개 이상이 최소 안전은행이다. 연습160개와 별도.** 시험은행이 전체60개뿐이면 이 조건을 만족하지 못한다. 각 문항의 독립성은 문제상황/관찰/질문대상 기준이며 ID/숫자/선택지 치환은 제외.

- 부족하면 새 시험 생성 전 구체적인 부족 범위를 표시하고 실패시킨다. 과학근거가 있는데 75 생성실패를 몰래55로 축소하는 fallback 금지. 콘텐츠은행 완성 전 science75가 준비되었다고 선언하지 않는다.
- Firestore 규칙의 questions/initialAttempts==55 하드코딩(현재 rules 약76/93/195/196/225/226행)을 버전별 정확한 계약 검증으로 교체. 단순 `size==55 || size==75`만 열지 않는다. 새75는 science75 버전+정확한 총문항/섹션/답안 개수와 일치해야 한다. 원래 사용자권한/정답비공개/상태전이 규칙은 보존한다.
- 온라인 시험, 인쇄, OMR, 자동채점, 최초점수, 관리자 공개 전 정답비공개, 공개 후 영역별 결과/전체분모까지 두 버전 모두 검사한다. 과학은 새 답안형 없이 단일정답 객관식으로 기존 OMR 체계에 연결.
- 서비스워커/정적파일과 Firestore 규칙의 버전 조합을 문서화. **운영 rules 배포는 구현/로컬검증과 별개이며 현재 배포 승인 없음.** 로컬 코드만75고 서버규칙은55인 상태를 배포완료로 보고하지 않는다.

## 7. 지구과학 모형 정확성

- 지구 자전: 약 하루, 낮밤 경계와 지표 관찰점을 보여준다. 실제 자전/공전 기간을 문제로 쓰려면 '약' 또는 하루의 정의를 적절히 표현한다.
- 지구의 태양 공전: 약1년. 태양-지구 거리/천체 크기/속도는 비례 아님을 표시. 계절을 다루면 기울어진 자전축의 방향을 공전 내내 유지하고 반구별 일사 차이를 보여준다. 복잡하면 계절 설명은 별도 후속단원으로 넘긴다.
- 태양계의 은하 중심 공전: 약2억3천만 년. 자전·공전·은하 공전을 세개의 독립 탭/시간척도로 제시. 축소 배율과 시간압축이 서로 다름을 각 탭에 상시 표시한다.

## 8. Level 2/3 확장점

- Level2: 생명과학/물리/화학/지구과학 4영역 유지. 내부 `internalBand:'m1'|'m2'|'m3'`를 콘텐츠/추천에 쓰되 학생 UI는 `Level 2`와 단원만 노출. 학년을 공개 레벨과 동일시하지 않는다.
- Level3: 통합과학 기초와 선택과정 연결을 `track:'integrated'|'biology'|'physics'|'chemistry'|'earth'`로 구분 가능하게 한다. Level3=고1 같은 자동매핑 금지. 사용자의 선택과 학습 이력으로 범위를 정한다.
- 이번 Level1에서 Level2 자동승급은 만들지 않는다. 아직 없는 문제로 이동하지 않도록 완료 후 다음 준비 안내.
- 단원마다 sourceRefs와 curriculumMapping(미검증이면 null)을 두어 나중에 공식교육과정과 검증 후 연결한다. 교과서 단원 배열 추정은 사실로 적지 않는다.
