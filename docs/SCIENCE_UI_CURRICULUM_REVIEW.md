# 과학 화면·전체 단원 목록 검토안

**추천: Level 1 초등 핵심 28단원(기존8·준비20) + 중학교 연결 탐구4(준비).** 단원 수와 묶음은 제품 구성 제안입니다. 초등3~6 주요 주제를 다루지만 공식 성취기준 전체와 항목별 대조는 아직 하지 않았습니다. **학년·학기 미확정**이며 인헌중 중1 첫 학기 진도와 같다고 표시하지 않습니다.

`기존`은 현재 학습·문항이 있는 단원입니다. 아래의 새3D까지 모두 완성했다는 뜻은 아닙니다. `준비`는 목록 제안만이며 시작·완료율에 넣지 않습니다. 이번은 문서·화면시안 검토만, 신규문항 설계/640문항·75시험 변경 없음.

## 화면 방향

- 청록·크림 유지. Level선택 → 생명과학/물리/화학/지구과학 **그림카드4개** → 단원목록. Level2에서 영역을 눌러도 Level1목록으로 바뀌지 않습니다.
- 학습 중 목록은 접고 `레벨 › 영역 › 단원 / 단원 바꾸기`만 남깁니다. 준비중Level2/3은 시작버튼 없이 상태를 설명합니다.
- **예측 → 조건 변경 → 3D관찰 → 원리 설명 → 확인** 흐름. 지구의 자전/태양공전/은하공전을 바꾸면 제목·본문·범례도 함께 바뀝니다.

## Level 1 전체 단원 제안

### 생명과학

| 단원 | 상태 | 조건 바꾸기 → 관찰 → 설명할 원리 |
|---|---|---|
| 동물의 생김새와 생활 | 준비 | 서식 환경 선택 → 발·몸·이동 방식 비교 → 생김새와 생활의 관계 |
| 동물의 한살이 | 준비 | 나비·개구리 단계 이동 → 몸의 변화 비교 → 성장 과정의 공통점과 차이 |
| 식물의 한살이와 씨의 퍼짐 | 준비 | 물·빛 조건을 하나씩 바꾸기 → 발아와 이후 생장 비교 → 발아 조건과 생장 조건 구분 |
| 식물의 몸과 물의 이동 | **기존** | 물 공급·잎 조건 변경 → 줄기 단면의 이동 경로 → 흡수·이동·증산 연결 |
| 꽃·열매·씨의 연결 | 준비 | 꽃의 부분과 과정 순서 선택 → 열매·씨가 생기는 위치 → 번식 과정 연결 |
| 우리 몸의 기관과 협력 | 준비 | 음식·공기 이동 경로 선택 → 소화·호흡·순환 경로 확대 → 기관별 역할과 협력 |
| 먹이 관계와 생태계 | **기존** | 생물·환경 조건 변경 → 먹이망의 연결 강조 → 영향 가능성과 여러 원인 구분 |

| 에너지의 이동과 전환 | 준비 | 에너지원·장치 선택 → 회전·빛·열의 경로 → 에너지의 형태 변화와 전달 |

## 중학교 연결 탐구 — 모두 준비

한 가지 조건만 바꾸는 실험 / 힘을 화살표·그래프로 읽기 / 입자로 상태 변화 설명하기 / 관찰 근거로 생물 분류하기. 초등개념을 중학의 탐구방식으로 연결하는 선택묶음이며 Level2전체과정이나 중1첫학기 시험범위를 대신하지 않습니다.

## 시각화·초등 누락 점검

- Three.js는 회전 장식이 아니라 **전체→확대·단면→변화 과정→조건 비교**에 사용합니다. 기존8 중 지구·열·식물부터 개선하고, 신규는 전기회로·빛/그림자·달·지층처럼 공간관계가 중요한 주제를 우선합니다.
- 달/계절은 같은 목록 아래 별도장면. 달의위상을 지구그림자로 설명하지 않으며, 지구3운동은 별도시간척도입니다. 성장·생태계 모형을 정확한 수치예측으로 포장하지 않습니다.
- 후속교육과정 대조 때 **미생물·균류/렌즈·굴절/기후·환경변화** 누락을 추가점검합니다. 관련단원 소주제로 검토하되 실제콘텐츠 없이는 포함완료로 세지 않습니다.
- 정지·초기화·모션줄이기·SVG대체 유지. 3D진행상태 때문에 기존퀴즈·기록이 달라지지 않습니다.
